Chapter 2 Background
2.1 Face Detection and Landmark Recognition
    Face detection is a fundamental task in computer vision that involves locating human faces in digital images. Modern approaches utilize machine learning models like MediaPipe's face detection and face mesh solutions to identify facial features. The face mesh model provides 468 landmark points on each detected face, enabling precise localization of facial features like eyes, nose, mouth, and facial contours. These landmarks form the foundation for facial expression analysis by providing quantitative measurements of facial feature positions and shapes.
2.2 Eye Aspect Ratio (EAR) for Expression Recognition
    The Eye Aspect Ratio (EAR) is a widely-used metric in facial expression analysis, particularly for eye state detection. For each eye, it's calculated as the ratio of vertical eye landmark distances to horizontal eye landmark distances. A low EAR value indicates closed or squinted eyes, while a higher EAR value indicates open eyes. This metric is critical for detecting expressions like squinting and can be used to identify blink patterns and drowsiness detection applications.
2.3 Mouth Aspect Ratio and Expression Classification
    Facial expression recognition often relies on geometric relationships between facial landmarks. For smile detection, the mouth width (distance between corner landmarks) compared to the nose distance and mouth opening ratio (vertical opening to width) provide key indicators. A smiling expression typically shows increased mouth width with raised corners, while surprised expressions show increased vertical mouth opening relative to width. These quantitative measures enable automated expression classification algorithms.

Chapter 5 Challenges and Solutions
5.1 Challenge 1 - Expression Recognition Sensitivity
Description:
Initial expression recognition thresholds were too strict, making it difficult to detect subtle expressions like gentle smiles or partial surprise. The algorithm was only recognizing very clear, exaggerated expressions, reducing its usefulness for natural facial expression detection.
Cause:
The threshold values for detecting expressions were set too high, requiring significant changes in facial feature geometry to trigger expression recognition. This resulted in many natural expressions being classified as "Neutral".
Solution:
Adjusted the sensitivity thresholds for expression detection by reducing the required mouth width change for smiles and mouth opening change for surprise. The thresholds were empirically tuned through testing with various facial expressions to achieve optimal sensitivity for natural expressions.
Outcome:
The algorithm now reliably detects more subtle expressions, making it more useful for real-world applications where people exhibit natural, less exaggerated facial expressions. The sensitivity for smile detection was improved by reducing mouth width thresholds from 0.18 to 0.13 and smile indicator thresholds from -0.02 to -0.01 for smile detection.
5.2 Challenge 2 - Real-time Display of Multiple Metrics
Description:
Displaying all calculated metrics while maintaining clear visualization of facial features was challenging. The video display was becoming cluttered with text overlays making it difficult to focus on the face while still accessing the quantitative information.
Solution:
Implemented a fixed display area in the top-left corner of the video window that shows all calculated metrics continuously. This separates the facial landmark visualization from the metric display, allowing clear viewing of both facial features and quantitative analysis results without visual interference. Only the expression type is displayed near the face bounding box to keep the facial region clean while providing essential classification information.
Outcome:
Cleaner visualization with clear separation between facial landmark detection and quantitative metrics display, improving both the readability of metrics and the clarity of facial feature visualization simultaneously.
